# 🐍 Estudos de Programação Orientada a Objetos (POO) em Python

Repositório dedicado ao estudo e aplicação prática dos conceitos fundamentais de POO em Python através da simulação de uma mecânica de combate.

## 📌 Conceitos Aplicados

* **Herança (`super()`):** Reaproveitamento da estrutura e atributos da classe base `Personagem` para as classes filhas `Guerreiro` e `Pally`.
* **Polimorfismo:** Sobrescrita do método `.atacar()` para adaptar o comportamento de cada classe (gerenciamento de flechas para o arqueiro e ataque direto para o guerreiro).
* **Encapsulamento:** Utilização de atributos privados (`__nome`, `__vida`, `__arma`) com métodos seletores (*getters*) para assegurar a integridade dos dados.
